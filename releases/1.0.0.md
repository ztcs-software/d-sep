First stable release

- Sorts D-Log, D-Log 2 and D-Log M clips into folders, renames them with a prefix, or both
- Copies or moves them, along with their `.LRF` and `.SRT` files
- Comes as an installer or a portable `.exe`

### Fixes since 1.0.0-beta-1

- Sorting again into a **Save to** folder inside the scanned folder now leaves the clips an earlier sort put there where they are, instead of copying them into another folder inside it
- Progress now counts only the clips that still need sorting, like the button does, so a sort picked up after a Cancel no longer counts the clips already done
- The portable download is now named `D-Sep_1.0.0_x64-portable.exe`
